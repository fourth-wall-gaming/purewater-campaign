# The Realm of Thornmere

`the-realm-of-thornmere.jpg` is the map of the kingdom. Canon:
`lore/geography/the-lands-of-thornmere.md`.

Unlike the city sheets, it is not cut from anything. It was generated from
`prompt.txt` with `../purewater-map.png` attached as a style reference only, then
corrected with `edit-purewater.txt` (Purewater had been drawn as an island out in
the sea, too big; `edit-purewater-mask.png` limits that edit to the Mouth). The
model lettered it itself. The full-size PNG is not tracked.
