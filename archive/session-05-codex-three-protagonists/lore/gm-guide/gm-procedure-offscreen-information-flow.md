Use this after an offscreen event establishes a fact.

1. Witnesses learn in the fact or beat write itself.
2. Identify only named NPCs with a live route to the news through an agenda, contacts, office, district, trade, or direct interest.
3. Run one track-who-knows batch using each NPC's Streetwise. Difficulty measures access to this news: Very Easy for their own agent reporting; Easy for their own district or trade; Standard for an active city network; Hard for indirect or distant news; Formidable for insulated circles; Herculean for something nearly buried.
4. If someone actively tried to keep the event secret, use --concealed-by so each NPC's inquiry is opposed by that character's Deceit.
5. The command skips existing knowers, saves only successful discoveries as rumor knowledge, and immediately runs the knowledge-agenda cascade.
6. Do not roll for the whole city. Anonymous public awareness and repeated incidents continue to use the awareness clocks in TABLE section 2c.
